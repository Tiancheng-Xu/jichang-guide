## 更新标准

1. 入口变更：核对新域名来源和完整链接参数，再更新首页与数据文件。
2. 套餐变更：记录公开来源、观察日期、有效期、价格与流量规则；登录后信息如需整理，不发布个人信息或订阅密钥。
3. 测试结果：使用选购指南的条件记录；把单次结果和长期观察分开。
4. 未确认信息：明确保留“待核验”；不自动刷新日期制造“每日实测”的印象。
5. 维护记录：通过 Git 提交保留实际变更。当前未部署定时监控，不承诺自动更新。
